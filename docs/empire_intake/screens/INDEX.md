# Empire ERP (`AMAZE 1.0`) — Master Visual Screenshot Catalog & UX Deconstruction

This living index tracks every Empire UI screenshot dropped into `docs/empire_intake/screens/`, automatically renamed by module, MS Access form engine, voucher `TYPE`, mode (`add`/`view`/`edit`), and active sub-tab.

## Naming Prefix Taxonomy (Scales to 100+ Screens)
- `00_shell_*` — Login, Home Switchboard, Top Menu Dropdowns (`INVENTORY`, `BILLING SYS.`, `GEN. ENTRIES`, `MASTERS`, `REPORTS`, `UTILITIES`, `CUSTOMISE`), Global Toolbars
- `01_challan_<TYPE>_*` — Polymorphic `CHALLAN` engine (`S1`, `O1`, `O13`–`O16`, `P2`, `p11`, `P4`, `P6`, `O4`–`O12`, `O45`, `P26`–`P29`, `P3`, `S2`, etc.)
- `02_purbill_<TYPE>_*` — `PURBILL` engine (`P1` Grey Purchase / Mill Despatch)
- `03_pinvtrn_*` — `PINVTRN` engine (Mill Despatch Program Entry)
- `04_jobbill_<TYPE>_*` — `JOBBILL` engine (`J1` Mill Receipt & Jobwork Billing)
- `05_salerec_<TYPE>_*` — `SALEREC` / `PURTALLY` engine (`B1`/`B2`/`C1`/`C2` Bill-Wise Receipts & Payments)
- `06_billsdir_<TYPE>_*` — `BILLSDIR` engine (`P76` Broker Comm, `P91`/`P92` CN, `S91`/`S92` DN, `J2` JV, Expenses)
- `07_masters_*` — Master forms (`MASTER`, `QUAL`, `ACGROUP`, `SERIES`, `LABELS`, `HASTE`, `TRANSPORTS`)
- `08_reports_*` — Report engines (`RBILLDAYS`, `RMILLDES`, `RCOSTING`, `RBILLDET`, Trial Balance, Ledgers)
